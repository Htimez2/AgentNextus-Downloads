Desktop preview 3 for Windows, macOS (Apple Silicon and Intel) and Linux (AppImage and DEB). Download from https://agentnextus.com/#download.

## What is new since preview 2

- **Module library**: browse and download free, reviewed modules at https://agentnextus.com/modules/ without an account, or link the app to your agentnextus.com account (Modules → Website library) to install, update and reinstall modules from your library on any computer. "Install in Agent Nextus" links on the website open the app you already have running.
- **Upload to website**: submit any module, including ones your agents built, for review from the Modules page. Nothing is public until an administrator approves it.
- **Module updates** keep room windows and saved state, and are refused (with no changes) if a new version can't accept a room's saved state. Local and agent-built modules are never overwritten.
- **Pop-out windows** dock back into the main window instead of turning into a second copy of the app.
- **Bug reports** go privately to the Agent Nextus team with your approval: no destination to configure, a preview of exactly what is sent, a report ID when it is received, and safe retry.
- **Start Ollama server** button when Ollama is installed but not running.
- **GitHub sign-in** returns to the running app instead of opening the app in your browser.
- Agents need your approval for each action that creates a public repository, changes visibility, pushes code or publishes a package, even when commands are otherwise allowed.
- Chess shows every piece correctly.

## Notes

- These are unsigned preview packages. Windows SmartScreen and macOS Gatekeeper may show an unknown-publisher warning.
- Installing over preview 2 keeps your rooms, settings and installed modules (verified on Windows).
- Provider sign-in, usage limits and charges remain separate.
- Verify downloads against SHA256SUMS.txt.
